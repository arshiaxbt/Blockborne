# FastEVM Fighters

Educational auto-fighting game comparing MegaETH and Monad without declaring one globally better.

## Concept
Two fighters battle automatically:
- MegaETH: real-time Ethereum L2
- Monad: high-performance EVM L1

The user chooses:
1. Arena
2. MegaETH feature cards
3. Monad feature cards

The battle result depends on:
- arena stat weights
- selected cards
- tradeoffs
- small controlled randomness

The result screen must explain:
- why the winner won in this arena
- which features mattered most
- what tradeoffs were exposed
- reminder: this is contextual, not universal chain ranking

## Tone
Educational, fun, crypto-native, visual, not toxic.

## Tech
Next.js App Router, TypeScript, Tailwind, Framer Motion.

## MVP pages
Single page app:
1. Hero
2. Arena selection
3. Card selection
4. Battle simulation
5. Result explanation
